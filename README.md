# Correctness and robustness of LLM-generated Python code for hydroclimatic data processing

Supplementary material for the book chapter:

> López-Osorio RF, Pérez-Aguilar LY, López Sotelo Y, Quevedo García R, Quintero Morales MA,
> Monjardin-Armenta SA, Bernal Guadiana R ([year]) [Chapter title].
> In: [Book title]. Springer, [pages]. [DOI]

Data package: `llm-hydroclimatic-code-eval_data.zip`, attached to release [v1.0.0](https://github.com/perezlidia/llm-hydroclimatic-code-eval/releases/tag/v1.0.0) of this repository.

The study evaluated Python scripts generated by **GPT-6 Astra**, **Claude Opus 5.5** and
**Gemini 3.1 Pro** for six processing tasks on TerraClimate monthly precipitation (`ppt`) and
potential evapotranspiration (`pet`) for 1981–2025 in northwestern Mexico (Baja California,
Baja California Sur, Sonora and Sinaloa), in two exploratory phases:

| | Phase 1 | Phase 2 |
|---|---|---|
| Domain | Rectangular clip | State polygons |
| Reference | Python code | ArcMap 10.8 / ArcPy |
| Prompts | Initial prompts | Reformulated prompts (explicit NaN handling, self-contained code) |

| Task | Content |
|---|---|
| T1 | Temporal merging and spatial clipping |
| T2 | Detection and imputation of invalid values |
| T3 | Monthly climatology and annual totals |
| T4 | Climatic water balance (ppt − pet) |
| T5 | Linear trend, Mann–Kendall test and standardized anomalies |
| T6 | Safe loading of NetCDF files |

## Repository structure

```
prompts/            Prompts of both phases in English (original Spanish text in prompts/original_spanish/)
generated_code/     Scripts delivered by the models, unmodified (Spanish comments), plus repaired versions
reference/          Phase 1 Python reference (Phase 2 ArcMap reference rasters are in the data package)
evaluation/         Rubric and per-task scores
verification/       Scripts written by the authors to verify the outputs and produce the figures
results/logs/       Console output of every script run
results/tables/     Tables produced during verification
results/figures/    Figures of the chapter
data/               Description of the data package and the source data
```

`generated_code/` is the object of study: it is kept exactly as delivered by the models. Every
other script in this repository was written by the authors and does not modify the model code;
when a model computed a result without saving it, the result is retrieved by calling the model's
own functions or variables.

## Reproducing the results (Phase 2)

1. Install the environment (Python 3.12):
   ```
   pip install -r requirements.txt
   ```
2. Download `llm-hydroclimatic-code-eval_data.zip` from release v1.0.0 of this repository
   (Releases → v1.0.0 → Assets) and unzip it; see `data/README.md`.
3. Build the working directory:
   ```
   python verification/prepare_workdir.py --data <data folder> --out workdir
   cd workdir
   ```
4. Run the verification steps:

| Step | Command | Output | Chapter |
|---|---|---|---|
| T1 clips are identical across models | `python verify_t1_clips.py` | console | Sect. 3.4.1 |
| T1 comparison with ArcMap | `python spatial_figures.py T1` | `figures/fig3_t1_polygon_clip` | Fig. 3 |
| Run T2 scripts and store outputs | `python export_t2_outputs.py` | `T2_<model>.nc`, logs | Sect. 3.4.2 |
| Retrieve GPT-6 Astra's unsaved T2 result | `python export_t2_gpt_in_memory.py` | `T2_gpt6astra_in_memory.nc` | Sect. 3.4.2 |
| T2 figure and imputation error | `python spatial_figures.py T2` | `figures/fig4_t2_invalid_values` | Fig. 4 |
| T3 scripts | `python t3_<model>.py` | console | Table 7 |
| T3 figure | `python fig_t3_climatology.py` | `figures/fig5_t3_climatology` | Fig. 5 |
| T4 scripts and per-cell maps | `python export_t4_maps.py` | `T4_<model>.nc` | Table 8 |
| T4 cell-by-cell comparison | `python spatial_figures.py T4` | `figures/fig6_t4_water_balance`, `diff_T4_*.tif` | Fig. 6 |
| T5 scripts | `python t5_<model>.py` | console, CSV series | Table 9 |
| T5 figure | `python fig_t5_trend.py` | `figures/fig7_t5_trend` | Fig. 7 |
| T6 scripts (own tests) | `python t6_<model>.py` | console | Sect. 3.4.6 |
| T6 extended battery (10 cases) | `python t6_robustness_battery.py` | `T6_robustness_matrix.csv`, `figures/fig8_t6_robustness` | Fig. 8 |
| Scores | `python fig_scores.py` | `figures/fig2_scores` | Fig. 2 |

On Windows, run `set PYTHONIOENCODING=utf-8` first, so that console output containing
non-ASCII characters can be redirected to a file.
