# English translation of the generated code

Reading aid only. Each file here is an English translation of the file with the same path in
`../generated_code/`, which is the object of study and the version that was executed and evaluated.

- Only comments, docstrings and human-readable messages were translated. Code, identifiers
  (including Spanish variable names), file names and data keys are unchanged; an automatic check
  confirmed that every translated file has the same syntax tree as its original once string
  literals are masked.
- Strings that the code itself compares or uses as keys were kept in Spanish, with an English
  gloss in an inline comment (e.g. the expected error messages in the T6 self-tests of GPT-6 Astra).
- Running a translated file prints English messages and may write English free-text metadata;
  all results reported in the chapter come from the original files.
